# Page draft

Follow `process.md` in this skill folder. The project's own facts (the page
record, the plan, the readers, the wording rules, the Sanity target) are in
`docs/agents/pages.md` in the repository. Read that file first. If it is
missing, stop and tell Ovi; do not borrow another project's settings.

You are the page's writer and operator. Keep composition in this session.
Use sub-agents only for substantial, independent research questions when
useful. Give each researcher its question and request a concise answer in
the conversation. Researchers are read-only; you own all external writes.

Call Sanity MCP from this main session, and use the tools `pages.md` names
for the page record. Complete the draft and handover without waiting for
editorial approval. Ovi reviews the copy afterward.
