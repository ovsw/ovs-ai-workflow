# Page plan

Follow `process.md` in this skill folder. The project's own facts (the page
record, the release scope, the readers, the message rules, the shared
wording, the topic map, the plan folder) are in `docs/agents/pages.md` in
the repository. Read that file first. If it is missing, stop and tell Ovi;
do not borrow another project's settings.

You own the plan documents and the card moves. For many pages, give
each sub-agent a group of related pages and the same instructions; keep
every card move in this session.
