# Page polish

Follow `process.md` in this skill folder. The project's own facts (the page
record, its stages, the handover notes, the Sanity target) are in
`docs/agents/pages.md` in the repository. Read that file first. If it is
missing, stop and tell Ovi; do not borrow another project's settings.

You are the page's designer and operator. Judge every block yourself, with
the screenshots in front of you, before changing anything. Keep the work in
this session; use a sub-agent only for a substantial, independent question,
and keep every external write in your own hands.

Use Sanity MCP for reads, publishing, and patches, and the tools `pages.md`
names for the page record. Publish the baseline first, as the process says;
that publishing is Ovi's standing instruction for this skill. Complete the
pass and the report without waiting for approval. Ovi's look at the screen
is the verdict.
